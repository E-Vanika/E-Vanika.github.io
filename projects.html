02

Responsible ML · Cloud delivery

Zippy Kiddo

A responsive activity recommender that helps parents find practical ideas for children aged 3–12 using age, time, setting, energy, supervision, and materials. It avoids collecting unnecessary child data and keeps hard safety constraints deterministic.

A compact trained ranker improves ordering, but the application never depends blindly on it: artifact checksums pin the model, a quality gate tests retrieval accuracy, and deterministic ranking remains the safe fallback. Terraform, Ansible, immutable images, readiness checks, rollback, and external smoke tests operate the OCI deployment.

03

SRE · Production-like lab

Single-VM SRE Platform

A complete reliability system on a resource-constrained OCI VM. Terraform and Ansible provision it; Git-SHA images and serialized delivery make releases traceable; readiness gates and deterministic rollback protect changes; Grafana Cloud retains telemetry away from the host.

The platform defines a realistic 99.0% availability SLO, multi-window burn-rate policy, RED and USE signals, cross-service OpenTelemetry traces, runbooks, a blameless postmortem, and bounded CPU, memory, disk, and process failure drills. It explicitly documents that two containers on one VM are process redundancy—not high availability.
